## 🧠 Problem Statement
Coal mining in India faces critical operational, safety, and compliance hurdles:
*   **Paper-Based Audits**: Slow, manual statutory compliance forms (DGMS Forms 4A–7) leading to compliance backlogs.
*   **Audit Verification Gaps**: Vulnerability to retroactive and unverified inspection submissions without geographic and timestamp integrity.
*   **Hazard Blind Spots**: Fragmented ground-level hazard reporting causing delayed responses to strata movement, water logging, and methane build-ups.
*   **Reactive Safety Culture**: Lack of predictive intelligence to foresee risk escalation and historical accident trends across mining blocks.

## 💡 The Solution
KhananSathi unifies national governance, mine operations, inspection, and frontline safety into one cohesive ecosystem:
*   **Unified Multi-Role Command**: Tailored portals for National SuperAdmins, Mine Managers, Field Inspectors, and Frontline Workers.
*   **Interactive GIS Spatial Intelligence**: Real-time interactive mapping with satellite layers and coordinates of Indian coal blocks (Jharia, Korba, Singrauli, Raniganj, Talcher, etc.).
*   **Tamper-Proof Live Verification**: Hardware-enforced camera viewfinder and automated GPS watermarking that eliminate photo spoofing.
*   **Predictive AI Safety Engine**: Machine learning models forecasting coal mine star ratings, risk scores, and hazard likelihoods.
*   **Digital DGMS Statutory Forms**: One-click generation, validation, and official print rendering for DGMS Forms 4A, 4B, 4C, 5, 6, and 7.

## 🔍 Key Functionalities

### 👷 For Frontline Workers
*   **📱 Mobile-First Interface**: Clean, accessible UI designed for field devices and tablets.
*   **📍 Geofenced Attendance**: One-tap biometric and GPS-verified clock-in and clock-out logging.
*   **⚠️ Rapid Hazard Reporting**: On-site incident reporting with direct camera capture, categorization, and location lock.
*   **📅 Digital Leave Requests**: Apply for medical, statutory, and casual leave with real-time status tracking.
*   **📢 Safety Broadcasts**: Instant access to mine-wide safety bulletins and shift notices.

### 🔍 For Field Safety Inspectors
*   **📋 Dispatched Task Queue**: Real-time sync of official audit directives dispatched by mine managers.
*   **⚙️ Dynamic Audit Matrices**: Specialized compliance evaluation criteria for **Open Cast (OC)** and **Underground (UG)** mines.
*   **📸 Strict Live Camera Viewfinder**: In-app HTML5 camera capture (strictly blocks file uploads to prevent fraud).
*   **🌐 Automated GPS Watermarking**: Lat/Lng coordinates and UTC timestamps locked into inspection dossiers.
*   **📝 Instant Dossier Sync**: Direct upload to Firestore updating mine compliance status in real-time.

### 👔 For Mine Managers
*   **📊 Safety Operations Desk**: Overview of live hazards, active audits, and workforce attendance.
*   **🎯 Audit Verification Desk**: Evidence review interface with live-captured photo proofs, GPS verification, and scoring.
*   **🚀 Task Dispatch Center**: Assign and dispatch statutory audits directly to designated field safety inspectors.
*   **📈 Workforce Management**: Approve digital leave applications and review shift attendance logs.

### 🏛️ For National SuperAdmins
*   **🗺️ National GIS Command Center**: High-definition satellite GIS mapping of India's major coal blocks and subsidiaries (CIL, SCCL, ECL, BCCL, SECL, NCDC).
*   **📜 Statutory Forms Archive**: Central repository of DGMS Forms (4A, 4B, 4C, 5, 6, 7) with official printable views.
*   **👥 User Onboarding & RBAC**: Approve registration requests, manage identities, and enforce role-based access control.
*   **🚨 Emergency Broadcast System**: Dispatch national or regional safety directives across all connected mines.

## 🎯 Why This Project Matters
Unlike conventional record-keeping databases, KhananSathi enforces **active accountability, verifiable truth, and preventative safety**:
1.  **Tamper-Proof Verification**: Every field submission is physically bound to live device camera hardware and GPS coordinates, upholding Section 22 / 22A integrity under the Mines Act, 1952.
2.  **Zero-Harm Safety Vision**: Proactive hazard reporting and ML risk forecasting prevent fatal incidents before they occur.
3.  **Statutory Digital Transformation**: Eliminates manual paper lags by standardizing DGMS Forms into instant digital workflows.
4.  **National Scalability**: Cloud-native Firebase and FastAPI architecture capable of scaling across all coal subsidiaries in India.

---

## 📜 Statutory DGMS Standard Forms

KhananSathi natively implements the official statutory documentation required by the Directorate General of Mines Safety:

*   **DGMS Form 4A**: Notice of Accident / Dangerous Occurrence *(Mines Act §23, CMR 2017 Reg 8)*
*   **DGMS Form 4B**: Report of Fatal Accident / Serious Bodily Injury
*   **DGMS Form 4C**: Quarterly Return of Minor Accidents
*   **DGMS Form 5**: Notice of Notifiable Industrial Disease *(Mines Act §25)*
*   **DGMS Form 6**: Notice of Contravention and Inspector Directives *(Mines Act §22 / §22A)*
*   **DGMS Form 7**: Mine Manager Statutory Charge-Handover Report

## ⚡ Quick Start Guide

### 1. Frontend Setup
```bash
# Navigate to the frontend directory
cd frontend

# Install dependencies
npm install

# Start the Vite development server
npm run dev
```
Open **`http://localhost:5173`** in your browser.

---

### 2. Backend Setup (FastAPI)
```bash
# Navigate to the backend directory
cd backend

# Create and activate a Python virtual environment
python -m venv env

# On Windows:
env\Scripts\activate
# On Linux/macOS:
source env/bin/activate

# Install backend dependencies
pip install -r requirements.txt

# Start the FastAPI server
uvicorn app.main:app --reload --port 8000
```
- **API Docs (Swagger UI)**: `http://localhost:8000/docs`
- **Health Check**: `http://localhost:8000/api/v1/health`

---

### 3. Machine Learning Setup
```bash
# Navigate to the ML directory
cd ML

# Install ML requirements
pip install -r requirements.txt

# Run inference test
python use_saved_model.py
```
